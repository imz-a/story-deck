# 分镜阁 StoryDeck · AI 剧情图文工作台

> 把一个故事灵感拆成分镜独白与画面描述，再用 AI 渲染 9:16 竖版画面，像刷抖音一样翻页预览你自己的「AI 剧情图文」。

## 定调

- **受众**：想做抖音「AI 剧情图文」（无限流 / 规则怪谈 / 民国奇幻题材）的创作者
- **风格**：暗夜鎏金 · 电影感——暖炭黑表面 + 烛光金强调色，思源宋体大标题（展示字）× 思源黑体（正文），搭配 Cormorant Garamond 斜体编号
- **记忆点**：可交互的 9:16「预览台」手机框，模拟读者刷图的翻页体验（点击 / ←→ 键翻页）

## 功能

### 三步工作台

| 工坊 | 能力 |
|------|------|
| **01 剧本工坊** | 一句话设定 → 分镜独白（字幕）+ 画面描述（生图指令）。每格可编辑、可删除、可单独重绘 |
| **02 生图工坊** | 每格渲染 768×1344 竖版画面；风格预设（民国奇幻 / 电影写实 / 暗黑惊悚 / 国风志怪）；同种子同构图 |
| **03 预览台** | 竖版翻页预览 + 进度条；复制全部独白 / 导出 Markdown 脚本 / 逐张下载成图 |

### 双轨驱动（文案与生图分开）

| 模块 | 免费模式 | 进阶模式 |
|------|----------|----------|
| 文案 | **内置分镜引擎**：按题材叙事弧线（入场→规则→异常→危机→反转→钩子）本地抽卡生成，零配置零成本 | 任何 OpenAI 兼容对话接口（DeepSeek / 硅基流动 / 智谱…），自填 Base URL + Key + 模型名 |
| 生图 | **免密钥通道**（Pollinations 公共服务，尽力而为）+ **Canvas 字幕卡兜底**：失败时自动降级为内置鎏金字幕卡，流程永不中断 | 任何 OpenAI 兼容图像接口（自填地址 + Key，需允许 CORS） |

> 所有密钥只保存在你自己的浏览器 localStorage 中，不经过任何第三方服务器——本站是纯静态页面。

## 运行

纯静态站点，无构建步骤：

```bash
# 直接双击 index.html，或起一个静态服务
python -m http.server 8000
# 打开 http://localhost:8000
```

## 技术结构

```
story-deck/
├── index.html            # 语义化结构 + 设置弹层
├── styles/
│   ├── tokens.css        # 设计令牌：颜色 / 字阶 / 间距 / 阴影 / 动效
│   ├── base.css          # 重置 / 排版 / 氛围层（鎏金渐变 + 颗粒）/ 降级动效
│   └── components.css    # 工作台组件 / 手机预览框 / 弹层 / Toast
└── scripts/
    └── main.js           # 设置存取 / 内置分镜引擎 / LLM 调用 / 生图与兜底 / 预览 / 导出
```

## 无障碍与适配

- 正文对比度 ≥ 4.5:1，交互目标 ≥ 44×44px，`:focus-visible` 金色描边
- `prefers-reduced-motion: reduce` 下关闭全部动效
- 375 / 768 / 1440px 三档响应式（移动端工作台单列堆叠）
